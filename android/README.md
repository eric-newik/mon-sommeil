# Démarrer l'appli Android avec Claude Code

1. **Sur le téléphone OPPO** : Paramètres › À propos du téléphone › Version, touche 7 fois « Numéro de version ». Ensuite, Paramètres › Paramètres supplémentaires › Options pour les développeurs › active « Débogage USB ».
2. **Sur l'ordinateur** : installe Android Studio (gratuit, https://developer.android.com/studio) et lance-le une première fois pour qu'il télécharge le SDK.
3. Récupère ce dépôt : `git clone https://github.com/eric-newik/mon-sommeil` (ou « Code › Download ZIP » sur GitHub).
4. Ouvre un terminal dans le dossier `mon-sommeil/android`, lance `claude`, et écris :
   > Lis CLAUDE.md et commence l'étape 1.
5. Branche le téléphone en USB et accepte l'autorisation de débogage quand elle s'affiche.

Le cahier des charges complet est dans `CLAUDE.md`, l'icône dans `icone/`.
